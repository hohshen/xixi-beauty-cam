# Testing

**Automated:** `npm test` (Node, no browser) and `tests/browser/warp-test.html` (Chrome). **Manual:** the checklist below, using a group photo through _Use a photo as the camera_.

## Automated tests

| Command / page                      | What it covers                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `node tests/presets.test.mjs`       | Both built-in sets load (6 filters, 6 beauty presets), filter values match the planned table, defaults, intensity and fine-tuning math for both tabs, filter parameters reach the whole-frame grading uniforms, beauty parameters reach only the beauty uniforms, beauty-off faces never enter the beauty mask or the warp, shader order (beauty, then grading), per-tab localStorage, static page structure (two tabs, each with its own intensity slider and preset bar)                                           |
| `node tests/preset-format.test.mjs` | Both formats (`xixi-filter`, `xixi-beauty`): valid, missing fields, out of range, extra fields, malicious text; schema and validator agree; import sorts files by `format`; custom preset storage per kind; no `eval` / dynamic import / unsafe HTML sinks                                                                                                                                                                                                                                                           |
| `node tests/pwa.test.mjs`           | Manifest and icons, service-worker cache list = files in `app/`, cache version, SHA-256 of the vendored MediaPipe files, no external URLs in the app, CSP (`connect-src 'self'`, same in `index.html` and `_headers`), mobile structure (`playsinline`, safe areas, camera switch, share), auto-quality steps                                                                                                                                                                                                        |
| `node scripts/validate-presets.mjs` | Every built-in filter and beauty preset against its `schema.json`, file name = `<id>.xixi-filter.json` / `<id>.xixi-beauty.json`, `CC0-1.0`, index consistency                                                                                                                                                                                                                                                                                                                                                       |
| `tests/browser/warp-test.html`      | Warp and shader on cartoon faces with synthetic landmarks, pixel comparisons, per-frame timing. T7 checks the filter: all-zero filter is pixel-identical to no filter, the beauty-off face and background are graded, and in the beauty-difference view the beauty-off face is pure black for every built-in filter; it also prints sampled colors per filter and the cost of the heaviest filter. Serve the repo root (`python3 -m http.server 8001`) and open `http://localhost:8001/tests/browser/warp-test.html` |

## Manual checklist

Use a group photo with three frontal faces (each at least ~10% of the frame width) that you are allowed to use. **Keep test photos out of the repository**, and do not attach screenshots with identifiable faces to issues or PRs.

Start the app, open DevTools → Network with _Preserve log_, then:

**Shader check in a browser** (needed after any change to `renderer.js`): serve the repo root and open `tests/browser/warp-test.html`; every line must start with ✅, including the T7 filter lines. Record the `⏱` lines (per-frame ms) and the `🎨` line (sampled colors per filter) in the PR.

With a real camera, also check: IDs survive a short (< 1.5 s) exit from the frame, two people side by side at 1280×720 keep ≥ 24 fps, and a beauty-off face right next to a beauty-on face stays black in the difference view.
