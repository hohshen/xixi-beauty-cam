# Getting help

- **Read the docs first:** [README](README.md) (quick start, browser support), [filter guide](docs/filters.md), [architecture and known limitations](docs/architecture.md).
- **Questions and ideas:** open an issue using the **Feature request** form, or ask in [GitHub Discussions](https://github.com/hohshen/xixi-beauty-cam/discussions) if it is enabled.
- **Something is broken:** open a **Bug report** with your browser, OS, device and the steps to reproduce. The fps panel numbers (⋯ menu → fps) help a lot for performance problems.
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).

When sharing screenshots, please do not post images of people who have not agreed to it. A cartoon face or a description is usually enough.

This is a volunteer project; there is no guaranteed response time.
